# Ryzume AI

**AI career toolkit** — live at [ryzume.in](https://ryzume.in)

One-time fee, no subscription. India-first.

## What it does

- **Resume builder** — plain, recruiter-approved formatting (ATS-friendly)
- **ATS scorer** — scan any resume against a job description
- **Cover letter generator**
- **Interview Q&A prep** (text practice)
- **Skill gap analyzer, offer decoder, salary negotiation coach, self-appraisal writer, resignation letter drafter**

## Model

Pay once, recharge like mobile — Starter ₹199 / Pro ₹499 one-time, monthly
allowance refresh. No subscriptions, no hidden pricing.

## Status

Live in production at [ryzume.in](https://ryzume.in). Source is private;
this repo is the public project page.
